## О проекте
**Linkify** - простое, но функциональное web-приложение для работы со <span style="background-color: yellow;">связанными</span> конспектами и заметками.

С помощью этого сервиса можно не только сохранять важные для себя факты, но и связывать их между собой. Благодяря этому ваше обучение может стать более интересным, эффективным и удобным.

> В основе проекта - методика Zettelcasten, но немного измененная

### Возможности сервиса:
- 👤 Авторизация и регистрация 

- 📝 Работа с папками и заметками внутри папок 

- 🎨 Форматирование текста внутри заметки (выделение курсивом, жирным, работа с цветами и т.д.)
- 🖼️ Добавление картинок в контент заметки

- 🔗 Добавление ссылки из одной заметки на другие (ключевая функция)
- ⚙️Настройки персонализации: 
	- Изменение имени
	- Выбор аватарки
	- Выбор акцентного цвета
	- Темная и светлая темы

- 📊 Отдельная панель с dashboard, которая отображает важную информацию обо всех заметках пользователя

Эти функции помогут вам создать собственную базу знаний, которую можно использовать и в работе, и в учебе. А раздел с аналитикой (dashboard) поможеть оценивать качество вашей базы знаний и улучшать его!

**Сервис имеет мобильную, планшетную и десктопные версии, пользоваться можно с любого устройства.**

### Инструкция по запуску проекта

#### 1. Необходимые условия
Убедитесь, что на вашем компьютере установлены:

- **Python** (проверить можно командой `python --version`). Если Python не установлен, скачайте и установите его с официального сайта Python.org.
- **pip**: Обычно поставляется вместе с Python.

#### 2. Распаковка проекта
Распакуйте архив с проектом в выбранную директорию.

#### 3. Запуск в VS Code
1. Откройте папку проекта в VS Code: `File > Open Folder`.

2. Создайте виртуальное окружение: 	
	- Откройте палитру команд: `View > Command Palette`.
	- Выберите Python: `Create Environment`.

	- Выберите `venv` в качестве названия окружения и укажите интерпретатор Python, который хотите использовать.

3. Активируйте виртуальное окружение: (VS Code обычно предлагает активировать окружение автоматически)

4. Установите зависимости: В терминале выполните команду `pip install -r requirements.txt`.

5. Запуск приложения:
	- Установите файл `app.py` как файл запуска.
	- Запустите приложение, выбрав `Debug > Start Debugging`. VS Code автоматически откроет браузер с запущенным приложением.
	- Либо запустите через терминал командой `python app.py`.

После этого работать с приложением можно по ссылке (в редких случаях порт может измениться, но в терминале будет видна работающая ссылка, всегда можно проверить) `http://127.0.0.1:5000`

#### 4 Запуск в Pycharm
1. Откройте проект в PyCharm: `File > Open` выберите папку с проектом.
2. PyCharm предложит создать виртуальное окружение. Если этого не произошло, создайте его вручную.
3. Установите зависимости: Откройте терминал в PyCharm (`View > Tool Windows > Terminal`) и выполните команду `pip install -r requirements.txt`.

4. Запуск приложения:
	- Установите файл `app.py` как файл запуска.
	- Запустите приложение, нажав `Run`.
	- Либо запустите через терминал командой `python app.py`.

После этого работать с приложением можно по ссылке (в редких случая порт может измениться, но в терминале будет видна работающая ссылка) `http://127.0.0.1:5000`
